# Prompt — Método "100 mil/mês com o Claude" (Thiago Boeira)

> Baseado no vídeo *"COMO EU FAÇO +100 MIL/MÊS COM O CLAUDE (e não é usando prompt)"*.
> Ideia central: o ganho não está em "prompt bonito", e sim em usar os **recursos**
> do Claude (Skills, Claude Code, Projects, Artifacts) pra montar uma operação.

## Os 6 pilares

| # | Recurso | Pra que serve |
|---|---------|---------------|
| 1 | **Skills** | Automatizar tarefas repetitivas (cria uma vez, reusa sempre) |
| 2 | **Claude Code** | Montar "bots"/automações — ex.: alerta de vídeo viralizando |
| 3 | **Página de vendas** | Gerar copy/landing de alta conversão |
| 4 | **Projects** | Ambientes que guardam contexto (não repetir tudo sempre) |
| 5 | **Artifacts** | Editar visualmente em tempo real (páginas, criativos) |
| 6 | **Análise de campanha** | Analisar métricas de tráfego e otimizar |

---

## O PROMPT (cola no Claude)

```
Você é meu estrategista de operação com IA, no estilo do método do Thiago Boeira
(usar os RECURSOS do Claude, não só prompt solto). Vamos aplicar os 6 pilares abaixo
ao MEU negócio.

CONTEXTO DO MEU CANAL/NEGÓCIO:
- Nicho: [ex.: emagrecimento / finanças / etc.]
- O que eu vendo/promovo: [produto, afiliado, serviço...]
- Onde rodo tráfego/publico: [Meta Ads, YouTube, TikTok...]
- Meu objetivo dos próximos 30 dias: [ex.: escalar de X pra Y]

Quero que você me ajude, um pilar de cada vez, começando pelo pilar 1:

1) SKILLS — Liste as 5 tarefas repetitivas que EU mais faço e que dá pra virar
   uma Skill reutilizável. Pra cada uma, escreva a Skill pronta.

2) CLAUDE CODE (automação) — Me proponha 1 automação simples pra começar
   (ex.: monitorar quando um vídeo/criativo está viralizando e me avisar).
   Explique o passo a passo pra montar.

3) PÁGINA DE VENDAS — Gere uma landing/copy de alta conversão pro meu produto,
   com headline, provas, objeções e CTA. Me entregue como Artifact editável.

4) PROJECTS — Monte a estrutura de um Project (instruções + arquivos de contexto)
   pra eu não precisar reexplicar meu negócio toda vez.

5) ARTIFACTS — Refine visualmente o que criamos (página/criativo) em tempo real,
   me mostrando variações pra eu escolher.

6) ANÁLISE DE CAMPANHA — Quando eu colar minhas métricas (CPM, CTR, CPA, ROAS...),
   me diga o que cortar, o que escalar e o próximo teste.

REGRAS:
- Fale em português, direto ao ponto, com passo a passo acionável.
- Não avance de pilar sem eu confirmar.
- Sempre que fizer sentido, entregue como Skill, Project ou Artifact — não só texto.

Comece agora perguntando o que faltar do CONTEXTO e depois vá pro pilar 1.
```

---

## Notas rápidas

- **Dica bônus de economia de tokens** (também circula muito): use o modelo certo pra
  cada tarefa (Haiku = simples, Sonnet = dia a dia, Opus = complexo); tarefa nova =
  conversa nova; não ative várias Skills na mesma conversa.
- Se o "canal" for **tráfego pago (Meta Ads)**, dá pra fazer o **pilar 6** com dados
  reais das campanhas.
